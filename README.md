# Roster Master Desktop

Desktop-first / Offline-first HR Workforce Management System.

## Phase 0 goals
- Windows desktop application
- Local SQLite database
- Login and role-based access control (RBAC)
- Data-scope permissions by company / department
- Audit log for sensitive HR changes
- Preserve and migrate proven business rules from Roster Master v5.55
- Prepare for future central sync and AI integration

## Status
Initial architecture bootstrap.
